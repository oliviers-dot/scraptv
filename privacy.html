Privacy policy

ScrapTV · Last updated: November 18, 2026

What ScrapTV is

ScrapTV is a macOS application that runs on the user's own computer. It helps a video team prepare videos and upload them to a YouTube channel the user manages.

Google account access

When the user signs in with Google, ScrapTV asks for permission to manage the user's YouTube videos. This access is used only to upload videos, thumbnails, captions, titles, descriptions and playlist entries to the channel the user chooses, and to read that channel's name so the user can confirm where videos will be published.

The access token is stored only on the user's Mac. It is never sent to the developer or to any third party.

Data collected

ScrapTV does not collect, sell or share any personal data. The developer operates no server and receives no data from the application. There is no analytics or advertising.

Data stored on the computer

Downloaded video files are stored on the user's Mac and deleted automatically after 36 hours. Settings and the activity log stay on the Mac. All processing, including AI processing, happens locally.

Revoking access

The user can disconnect YouTube from ScrapTV's settings at any time, or revoke access from the Google account page: myaccount.google.com/permissions.

Google API Services

ScrapTV's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. ScrapTV uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
