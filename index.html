ScrapTV

An internal desktop tool for a video team

ScrapTV is a macOS application used by a small video team to prepare recordings of public meetings and press briefings and publish them to a YouTube channel that the team manages.

The application runs entirely on the user's own Mac. It uses the YouTube Data API only to upload videos, thumbnails, captions and metadata (titles, descriptions, playlists) to the channel the user selects when signing in.

ScrapTV is not a public service: there is no sign-up, no website account and no server operated by the developer.
